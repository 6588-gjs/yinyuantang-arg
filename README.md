# 阴缘堂 · 冥婚恐怖 ARG

> 「阴阳两隔，亦可结缘。百年老号，为您牵线。」

一个伪装成"阴婚介绍所官网"的恐怖解谜网页。表面是正常的中介网站，实则处处透着诡异。**全部内容藏在一个 `index.html` 里，零外部资源依赖**——图片是 Canvas/SVG 程序化生成，音效由 Web Audio API 实时合成。

## 玩法

- 页面底部有一个搜索框：**请输入您要查询的服务…**
- 关键词**不做任何高亮**，需要从每一页的字里行间自己提取
- 输入正确 → 页面渐变黑，解锁新宗卷（逐字"打字机"呈现）
- 输入错误 → 只有一句极淡的「本所无此记录」
- 某些词是禁忌：输入后只会浮出血红色警告，不会跳转
- 解锁深卷后，有概率触发全屏突脸惊吓（概率随进度递增，最终卷必触发）

## 安全提示

- 首次打开会询问是否启用**突脸惊吓与尖叫声**（Web Audio，音量较大）
- 惊吓效果可在页面底部随时开关，设置存于 `localStorage`
- 若感不适，请立即关闭页面
- 请勿在公共场合或安静环境开声音游玩

## 技术细节

- 纯静态单文件：HTML + CSS + JavaScript，无构建、无框架、无外链
- 视觉：暗红 `#8B0000` / 墨黑 `#0a0a0a` / 苍白 `#e8e0d8`，宋体/楷体，烛光闪烁、胶片噪点、文字抖动、摇晃的囍字
- 音频：Web Audio API 合成尖叫（800Hz→200Hz）、白噪音、低频心跳、电话铃
- 惊吓实现：全屏黑底 + SVG 绘制的苍白面孔（4 种变体）+ 2~3 秒纯黑屏后恢复
